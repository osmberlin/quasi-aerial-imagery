# Decisions log

## How to use

Append-only going forward: one row per decision, new rows at the bottom, never rewrite an old row. If a decision is reversed, add a new row and write `superseded by D-0xx` in the Status column of the old row. Status is `active`, `superseded by D-0xx`, `abandoned`, or `unclear` (the sources contradict each other, or the decision was only proposed). Source names the result row, the document or the person the decision rests on; "project record" means the project's working notes, which are not published. Rows before 2026-10-26 were condensed for publication: rows of earlier pipelines and superseded rows are shortened, internal remarks removed; IDs are unchanged. D-120 was given to two decisions on 2026-10-25; the viewer-measuring decision was renumbered to D-121 at publication, so D-120 is `--wall-range`.
